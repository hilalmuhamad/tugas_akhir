## Perbaikan Naskah di Luar Sitasi

Tiga hal yang ditemukan saat menelusuri naskah, terpisah dari urusan penomoran:

1. **Nomor Kepmendikbud salah.** Naskah menulis **3/P/2021**; yang benar
   **3/M/2021**. Kode `admin/scripts/train_random_forest_iku.py` sudah memakai
   nomor yang benar, jadi laporan dan sistem saat ini bertentangan.

2. **Sisa rancangan K-Means.** Kalimat penyangga `[5]` di Bab 2 menyebut
   variabel "dijadikan parameter titik pusat (*centroid*)". Istilah *centroid*
   milik algoritma *clustering*, sisa dari rancangan lama. Sistem final memakai
   Random Forest. Ganti dengan bahasa agregasi OLAP — misalnya "dijadikan
   dimensi dan *measure* pada Data Cube".

3. **DAFTAR PUSTAKA di `.docx` masih template kampus.** Isinya masih contoh
   bawaan (Dick 1990 tentang industri pelayaran, Franklin 1985 tentang
   matematika, artikel *fieldbus*). Daftar 28 entri belum pernah benar-benar
   masuk ke dokumen.

## Cara Memverifikasi Hasil Akhir

Setelah naskah disunting, jalankan pemeriksaan berikut agar tidak ada sitasi
menggantung maupun entri yatim:

```bash
python -c "import zipfile,re,html; x=zipfile.ZipFile(r'C:\Users\USER\Downloads\Hilal_Laporan Tugas Akhir.docx').read('word/document.xml').decode('utf8','ignore'); t=html.unescape(re.sub(r'<[^>]+>','',re.sub(r'</w:p>','\n',x))); print(sorted(set(int(n) for n in re.findall(r'\[(\d{1,2})\]',t))))"
```

Keluarannya harus berupa deret utuh `1, 2, 3, …, N` tanpa lompatan.

Daftar periksa:

- [ ] Setiap `[n]` dalam teks punya entri di DAFTAR PUSTAKA
- [ ] Setiap entri DAFTAR PUSTAKA dikutip minimal sekali di dalam teks
- [ ] Nomor sitasi pertama pada tiap bab menaik secara monoton (aturan IEEE)
- [ ] Kata "centroid" tidak lagi muncul di mana pun
- [ ] `3/M/2021`, bukan `3/P/2021`
- [ ] **Seluruh kolom "Dicek" di atas sudah ✔ hasil penelusuran Anda sendiri**
