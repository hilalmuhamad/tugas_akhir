# Smart Career Matching Alumni

## Project Overview

Aplikasi web untuk membantu alumni menemukan pekerjaan yang sesuai menggunakan Job Matching berbasis Natural Language Search.

Dashboard analitik menggunakan OLAP.

Frontend menggunakan React.

Backend menggunakan Laravel REST API.

Database menggunakan MySQL.

---

## Technology

- React 19

- React Router

- Axios
- React Hook Form

- React Icons

Backend

- Laravel 12
- Sanctum
- REST API

Database

- MySQL

---

## Architecture

Feature-based architecture.

Never use MVC inside React.

Never generate Blade.

Never generate Vue.

Always use reusable component.

Always use Tailwind.

Always use React Router.

Always separate UI and business logic.

## Folder Rules
